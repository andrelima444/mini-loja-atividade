# Vitrine Digital

Mini loja demonstrativa feita para a atividade com React, Axios, Fake Store API, PrimeReact e PrimeFlex.

## Executar
1. Extraia o ZIP e abra a pasta no VS Code.
2. No terminal, execute `npm install`.
3. Execute `npm start`.

## Componentes
- `ProductList`: consulta a Fake Store API com Axios e lista os produtos.
- `ProductCard`: apresenta cada produto em um Card do PrimeReact.
- `ProductForm`: permite cadastrar um produto e adicioná-lo à lista em tela.
- `App`: organiza a página e os componentes.

Os produtos cadastrados pelo formulário ficam no estado da aplicação durante a execução. O cadastro não é persistido na API.
